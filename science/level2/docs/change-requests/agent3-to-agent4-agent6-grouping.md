# C3 Level 2 discovery and viewer grouping

Each approved settlement is a v1 raster dataset with product level `level2`, year `2011`, units `people_per_cell` and an independent ID/version. Group the real entries by `provenance.group_id = india-level2-2011`. Use `synthetic-india-level2-2011` for the synthetic fixtures and present it separately. Preserve Census ID, settlement name, source scale, target resolution and coverage in the metadata or info panel. Tile services retain the per-town IDs and CRS and can use their existing WebMercator routes.

Agent 4 owns any metadata publication change needed to expose `group_id` in public collection discovery. The catalog already accepts it under provenance. Add it without removing existing fields or changing collection URLs. The viewer can render several separate sources in one logical group. Use consistent styling and a visible NoData state. Fine- and coarse-grid counts are tied to different pixel supports. For quantitative comparison use the matched-support aggregates; a viewer may show each native resolution separately with its units. Use the generated synthetic manifest from [the README](../../README.md) to test listing, group separation, town navigation and direct tile and download requests.
